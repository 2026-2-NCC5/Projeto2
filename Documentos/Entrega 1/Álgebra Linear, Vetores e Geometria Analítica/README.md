# Como executar a Entrega 1

## Estrutura da pasta

Mantenha o notebook e a pasta `Base` organizados assim:

```text
Entrega_Algebra_Linear/
├── Entrega_1_Algebra_Linear.ipynb
└── Base/
    ├── Contato.xlsx
    ├── Financeiro.xlsx
    ├── Historico.xlsx
    ├── Matriculas.xlsx
    └── Relacionamentos.xlsx
```

## Dependências

É necessário ter o Python 3 instalado. No terminal, dentro da pasta da entrega, execute:

```powershell
pip install pandas numpy openpyxl jupyter
```

## Execução

Inicie uma das interfaces abaixo:

```powershell
jupyter notebook
```

ou:

```powershell
jupyter lab
```

No navegador:

1. Abra `Entrega_1_Algebra_Linear.ipynb`.
2. Selecione um kernel Python 3.
3. Clique em **Run All Cells**.
4. Aguarde a leitura das bases Financeiro e Histórico.
5. Confirme que nenhuma célula apresenta erro.
6. Salve o notebook com `Ctrl + S`.

O notebook entregue já contém as saídas calculadas.
