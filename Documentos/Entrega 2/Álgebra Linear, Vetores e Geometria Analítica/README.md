# Entrega 2 - Álgebra Linear

Este repositório contém o notebook da Entrega 2, que aplica Análise de Componentes Principais (PCA) à matriz construída na Entrega 1.

## Arquivo

- `Entrega_2_Algebra_Linear.ipynb`

## Dependências

```powershell
pip install pandas numpy openpyxl jupyter
```

## Execução local

Mantenha o notebook ao lado de uma pasta `Base` com os cinco arquivos Excel utilizados na Entrega 1. Em seguida, execute:

```powershell
jupyter notebook
```

Abra o notebook, selecione um kernel Python 3 e execute **Run All Cells**.

O notebook enviado já contém as saídas calculadas. As bases possuem dados restritos e não devem ser publicadas no GitHub.
